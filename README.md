# Trifid

A personal custom firmware for the M-VAVE FM-1 that turns it into an industrial feedback-noise instrument: a
Karplus-Strong string inside a feedback loop, excited by noise. The idea is borrowed from Synthux Academy's
Audrey II. Built on [fm1-base](https://github.com/charlesvestal/fm1-base).

Work in progress: see `docs/PRD.md`.
